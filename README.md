# 🎓 Análise de Desempenho Acadêmico e Hábitos de Estudo

Este repositório contém um projeto prático de **Análise Exploratória de Dados (EDA)** em Python focado em entender como os hábitos de estudo, horas de sono, frequência escolar e o uso de tecnologias impactam no desempenho acadêmico dos estudantes.

---

## 📌 Sobre o Projeto

O objetivo principal desta análise é identificar padrões e correlações entre a rotina dos alunos e suas notas finais.

### 🎯 Principais Pergunta Analisadas:
- Qual é a relação entre o tempo de estudo semanal e a pontuação final?
- A quantidade de horas de sono impacta diretamente no rendimento acadêmico?
- Como a frequência escolar e a participação em atividades influenciam na média das notas?
